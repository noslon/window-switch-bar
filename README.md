# Window Switch Bar

**Switch between open VS Code windows in one click.**

Your other windows appear in the status bar. Click one to jump to it.

## Settings

| Setting | Default | Options |
| --- | --- | --- |
| `windowswitchbar.display` | `buttons` | `buttons`, `dropdown` |
| `windowswitchbar.position` | `left` | `left`, `right` |

Change them in **Settings** (search `windowswitchbar`), or with the Command Palette: **Show as Buttons**, **Show as Dropdown**, **Show on Left**, **Show on Right**.

Changes apply right away.
